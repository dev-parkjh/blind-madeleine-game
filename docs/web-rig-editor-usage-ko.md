# 웹 리그 편집기 사용법

`tools/live2d-editor`는 분리된 캐릭터 이미지 파츠를 리그로 묶고, 게임에서 사용할 초상화 PNG와 `.live2d-web.json` 모델을 내보내는 전용 웹 도구입니다. 저장 포맷은 프로젝트 전용 클린룸 형식이며, Live2D 원본 포맷을 사용하지 않습니다.

## 실행

통합 데이터 에디터(`tools/editor`)에서 캐릭터의 `Live2D 편집` 버튼을 누르면 같은 캐릭터와 초상화 상태로 열립니다. 단독 실행이 필요하면 다음 명령을 사용합니다.

```bash
cd tools/live2d-editor
npm run start
```

기본 주소는 `http://127.0.0.1:5187`입니다. 포트를 바꾸려면 `HOST=127.0.0.1 PORT=5190 npm run start`처럼 실행합니다.

## 기본 흐름

1. 상단에서 캐릭터를 선택하거나 `새 캐릭터`를 만듭니다.
2. `초상화 상태`에 `default`, `happy`, `idle_loop_f01`처럼 저장할 상태 이름을 입력합니다.
3. `이미지 추가`로 PNG/JPEG/WebP 파츠를 불러오거나, `레이어 가져오기`로 `layers.json`/`manifest.json`과 이미지 파일을 함께 불러옵니다.
4. 자동 배치가 어긋난 파츠는 캔버스에서 직접 이동하거나, 오른쪽 패널에서 위치/배율/회전 값을 조정합니다.
5. `리그 검사`의 `검사`를 눌러 오류가 없는지 확인합니다.
6. `초상화 저장`으로 게임용 PNG와 리그 JSON을 저장합니다.

## 레이어와 파츠

오른쪽 `레이어` 패널에서 기본 레이어, 디포머 그룹, 이미지 파츠를 선택합니다. 이미지 파츠는 표시 여부, 잠금, 단독 미리보기를 개별로 조절할 수 있습니다.

선택한 이미지 파츠 패널에서 자주 쓰는 항목은 다음과 같습니다.

- `이름`: 파츠 표시 이름입니다.
- `슬롯`: 생성 모델 앞/뒤 배치입니다.
- `그리기 순서`: 같은 슬롯 안에서 앞뒤 순서를 조정합니다.
- `표시 게이트`: 눈 깜빡임, 입 열림처럼 특정 파라미터 범위에서만 파츠를 보이게 합니다.
- `X/Y`, `X 배율/Y 배율`, `회전`: 캔버스 기준 배치값입니다.
- `히트 영역`: 런타임 클릭/터치 판정용 영역으로 내보낼 때 사용합니다.

`자동 바인딩`, `자동 배치`, `자동 부모`, `자동 표시 게이트`, `자동 메시`, `자동 변형`은 파일명과 레이어명을 분석해 기본 리깅을 다시 적용합니다. 수동 보정이 끝난 뒤에는 자동 명령이 기존 값을 덮을 수 있으므로 필요한 항목만 사용하세요.

## 파라미터와 디포머

가운데 아래 `파라미터` 패널에서 얼굴 방향, 눈, 입, 미소, 머리 흔들림, 호흡 값을 미리 볼 수 있습니다. `영향`을 선택하면 해당 파라미터가 어떤 파츠, 표시 게이트, 메시, 디포머, 모션에 연결되어 있는지 확인할 수 있습니다.

디포머 그룹은 여러 파츠를 한 번에 움직이거나 워프하는 묶음입니다. 이미지 파츠를 선택한 뒤 `디포머 추가`를 누르면 선택 파츠를 포함한 그룹을 만들 수 있고, `자동 그룹`은 머리/눈/입/몸 같은 그룹을 이름 기반으로 생성합니다.

## 표정 프리셋

왼쪽 `표정` 패널의 기본 표정 버튼은 현재 파라미터 값을 즉시 바꿉니다. 마음에 드는 상태가 있으면 `프리셋 저장`으로 저장합니다.

- `자동 프리셋`: 기본, 기쁨, 슬픔, 화남, 놀람, 걱정, 궁금함, 말하기, 깜빡임, 웃음 프리셋을 생성합니다.
- `JSON 내보내기` / `JSON 가져오기`: 다른 리그와 표정 프리셋을 공유합니다.
- `프리셋 내보내기`: 저장된 프리셋을 각각 게임 초상화 상태로 렌더링합니다.

## 모션과 대화 포즈

`모션` 패널에서 모션 클립을 만들고 키를 추가합니다. 타임라인을 움직인 뒤 파라미터를 조정하고 `키 추가`를 누르면 현재 시간에 키가 저장됩니다.

대화에 바로 쓰려면 다음 자동 생성 기능을 우선 사용합니다.

- `자동 대기`: 호흡, 머리 흔들림, 작은 시선 움직임이 있는 대기 루프를 만듭니다.
- `자동 말하기`: 입과 머리 움직임이 있는 말하기 루프를 만듭니다.
- `자동 입모양`: A/I/O/U/닫힘 입모양 세트를 만듭니다.
- `적응형 생성`: 대화 진행마다 자연스럽게 바뀔 적응형 포즈 세트를 만듭니다.
- `대화 세트 내보내기`: 대기, 말하기, 입모양, 적응형 포즈를 한 번에 생성하고 프레임으로 내보냅니다.

`대화 포즈 미리보기`에서 포즈 힌트나 대사를 넣고 `최적 포즈`, `대사 미리보기`, `이전/다음 포즈`를 사용하면 런타임이 선택할 대화 포즈를 미리 확인할 수 있습니다.

## 저장과 반영

`초상화 저장`은 다음 파일을 생성하거나 갱신합니다.

```text
assets/characters/{character_id}/{portrait_state}.png
assets/characters/{character_id}/{portrait_state}.live2d-web.json
data/characters/{character_id}.json
```

저장 후 통합 에디터의 캐릭터 화면에서 새로고침하거나 `Sync Live2D exports`를 실행하면 새 초상화와 모션 프레임 메타데이터를 확인할 수 있습니다.

## 백업과 이동

- `리그 내보내기`: 이미지 참조를 포함한 가벼운 리그 JSON을 저장합니다.
- `프로젝트 내보내기`: 이미지 파츠를 데이터 URL로 포함한 휴대용 프로젝트 번들을 저장합니다.
- `프로젝트 가져오기`: 번들의 이미지 파츠를 현재 캐릭터 폴더에 다시 업로드하고 리그를 복원합니다.
- `레이어 내보내기`: 현재 이미지 파츠 스택을 `*.layers.json` 형식으로 저장합니다.

작업 중에는 브라우저 로컬 저장소에 임시 저장본이 남습니다. 실수로 닫았거나 되돌리고 싶을 때 상단의 `임시 저장 복원`을 사용할 수 있습니다.
