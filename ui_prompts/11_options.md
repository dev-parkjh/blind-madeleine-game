# 11 Options

## 현재 UI

- 구현: `scripts/screens/options_screen.gd`
- 요소: 헤더 뒤로/초기화/저장 버튼, 볼륨/대사/화면 섹션 패널, 슬라이더, 토글, 오디오 미리듣기 버튼, 대사 미리보기, 화면 미리보기, 저장 토스트
- 현재 스타일: 검은 패널, 섹션 아이콘, 슬라이더/토글은 회색 중심

## 개별 프롬프트

```text
Create an options/settings screen UI kit for Blind Madeleine.

Composition: 1920x1080 screen mockup plus transparent asset sheet. Header with back/close, title safe area, reset button, save button. Three section panels: volume, dialogue, display. Inside panels: slider rows with label/value blank areas, range labels, toggle rows, preview buttons, dialogue preview card, display preview card, and save-complete toast.

Visual style: quiet operational menu inside a detective VN. Dense and practical, not a landing page. Smoky black panels, thin silver borders, muted brass accents, tiny rain/film grain, precise controls. Sliders should look like brushed metal tracks with a small ivory grabber. Toggles should be compact dark capsules with clear on/off states using muted silver, not bright green. Preview cards should look like miniature evidence windows.

Asset sheet requirements: transparent background; section panel, header button states, slider track/fill/grabber, toggle on/off/hover, preview card, small toast panel, generic icon slots. No readable text.
```
