# 01 Main Title

## 현재 UI

- 구현: `scripts/screens/main_title_screen.gd`
- 요소: `GameTitle`, `NewGamePanel`, `LoadGamePanel`, `ExtrasPanel`, 메뉴 버튼, 비활성 세이브 버튼, 라이선스/크레딧 상세 모달
- 현재 스타일: 검은 반투명 패널, 얇은 회색 테두리, 8px radius, 큰 버튼 3열 또는 모바일 세로 스택

## 개별 프롬프트

```text
Design a full-screen main title UI mockup and matching transparent component asset sheet for Blind Madeleine.

Composition for the mockup: 1920x1080 landscape. Large empty title safe area centered at the top for the game title. Under it, three equal menu panels arranged in columns: new game, load game, extras. On narrow/mobile variant, the same panels should stack vertically. Each panel has an empty header area and a vertical list of large buttons. Include one primary button style, secondary button style, disabled save-slot button style, and a small close/detail modal style for credits or licenses.

Visual style: detective case archive meets rainy city noir. Panels are smoky black glass over a subtle detective-office darkness, with thin muted-silver borders, tiny brass corner pins, faint paper grain, and very subtle red accent ticks. Buttons should look pressable but restrained: matte charcoal surfaces, brightened edge on hover/focus, slightly sunken pressed state. Include icon-safe circles or square slots, but do not draw specific icons or text.

Asset sheet requirements: transparent background; separate components for panel body, panel header strip, primary button normal/hover/focus/pressed/disabled, secondary button normal/hover/focus/pressed/disabled, modal panel, modal close button, thin divider line. Leave all text areas blank.
```
