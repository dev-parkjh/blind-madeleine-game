# 14 Shared Asset Sheet

## 목적

화면별 프롬프트를 쓰기 전에 공통 버튼/패널 스킨만 먼저 뽑고 싶을 때 사용합니다.

## 개별 프롬프트

```text
Create a complete shared UI skin asset sheet for Blind Madeleine, on a transparent background.

Include these reusable components:
1. Large panel frame, medium modal panel, small toast panel.
2. Surface cards for lists and inspectors.
3. Primary button states: normal, hover, focus, pressed, disabled.
4. Secondary button states: normal, hover, focus, pressed, disabled.
5. Ghost icon button states.
6. Choice button with label notch states.
7. Keyboard keycaps in small, medium, long sizes.
8. Input hint backing strips.
9. Slider track, fill, grabber.
10. Toggle on/off states.
11. Divider rules, corner pins, tiny red alert dot, brass binder rail, thin grid tile.
12. Focus ring and selection highlight overlays.

All components must share one coherent detective noir visual system: smoky black glass, muted silver borders, rain-blue shadows, aged paper grain, dark brass details, tiny red warning accents. Use 8-10 px panel radius and thin borders. Keep centers clean for text. Do not render any readable text. Lay out the sheet neatly with spacing so each asset can be cut out.
```
